Algorithm — Original
Step 1: Start.
Step 2: Initialize the linked list with head = NULL.
Step 3: Display the main menu with the following options:
         1. Add Food Order
         2. Display All Orders
         3. Search Order
         4. Delete Order
         5. Calculate Total Bill
         6. Exit
Step 4: Accept the user's choice.

Step 5: If the choice is 1, 
        accept the food order details and insert a new node into the linked list.
Step 6: If the choice is 2, 
        traverse the linked list and display all food orders.
Step 7: If the choice is 3,
        search for a particular order using its Order ID.
Step 8: If the choice is 4, 
        search for the specified order and delete its node from the linked list.
Step 9: If the choice is 5, 
         calculate and display the total bill of all orders.
Step 10: If the choice is 6, 
         terminate the program.
Step 11: If the choice is invalid, display an error message.

Step 12: Repeat Steps 3–11 until the user selects Exit.

Step 13: Stop.
