
 Problem Statement

To design, implement, and execute an improved Food Order Management System using a Doubly Linked List in C++ to provide a systematic, user-friendly, and efficient method of managing food orders in restaurants and college canteens. The system is developed to reduce the limitations of manual order processing, including difficulties in maintaining order details, tracking individual orders, handling cancellations, and calculating bills accurately. It provides a predefined food menu containing food item names and prices, from which users can select an item by entering its menu number and required quantity. Each order is assigned a unique Order ID and stored dynamically as a node containing the order ID, food item, quantity, total amount, and pointers to the previous and next nodes. The system supports adding new food orders, displaying all orders in forward order, displaying orders in reverse order, searching for a specific order using its Order ID, cancelling an existing order, displaying the food menu, and calculating the total bill of all active orders. The doubly linked list allows traversal in both forward and backward directions and supports insertion and deletion by updating the links between nodes. Dynamic memory allocation is used to manage the storage of orders according to the user's requirements, and memory is released when orders are cleared or the program is closed. This modified system demonstrates the practical implementation of doubly linked list operations, pointers, structures, functions, and dynamic memory management in C++. It improves the organization of food orders, simplifies billing, reduces manual effort, and provides a practical solution for understanding and applying linked list concepts in real-world applications.
