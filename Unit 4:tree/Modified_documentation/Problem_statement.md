 Problem Statement 

To design and implement an **Advanced Bus Route Management System using BST, AVL Tree, and Threaded BST in C++** to store, organize, and manage bus route information efficiently. The system maintains route details such as route number, bus name, source, and destination. It provides operations such as insertion, searching, deletion, displaying routes in sorted order, and finding minimum and maximum route numbers.

The system uses a Binary Search Tree for basic route management, an AVL Tree for self-balancing through LL, RR, LR, and RL rotations, and a Threaded BST for inorder traversal without recursion or an explicit stack. It also supports preorder, inorder, and postorder traversals and displays tree information such as height, root node, and leaf nodes. The project demonstrates the practical application of advanced tree data structures for systematic bus route record management.
