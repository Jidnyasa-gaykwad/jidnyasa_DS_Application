To design and implement a C++ program to demonstrate the four types of AVL tree rotations: LL (Left-Left), RR (Right-Right), LR (Left-Right), and RL (Right-Left). The program allows the user to select a rotation case, displays the tree before and after rotation, identifies the balance factor of the unbalanced node, and verifies that the inorder traversal remains unchanged after rotation. The objective is to understand how AVL rotations maintain the height balance of a binary search tree and improve its efficiency.
