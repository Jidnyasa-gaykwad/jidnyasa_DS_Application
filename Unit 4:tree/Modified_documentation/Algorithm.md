Step1 : Start.

Step 2: Initialize an empty Binary Search Tree (BST).

Step 3: Display the menu:

- Insert Employee ID
- Search Employee ID
- Delete Employee ID
- Display Employee IDs
- AVL Rotation Demonstration
- Exit
  
Step 4: Accept the user's choice.

Step 5: Insertion: Insert the employee ID into the BST according to BST rules.

Step 6: Searching: Search for the given employee ID and display whether it is found.

Step 7: Deletion: Delete the specified employee ID from the BST while maintaining BST properties.
Step 8: Display: Perform inorder traversal to display employee IDs in sorted order.
Step :. AVL Rotation Demonstration:
- Allow the user to select LL, RR, LR, or RL rotation.
- Insert suitable values to demonstrate the selected case.
- Calculate and display the balance factor of each relevant node.
- Perform the required rotation.
- Store the inorder traversal before rotation.
- Perform inorder traversal after rotation and compare both results.
- Display whether the inorder traversal remains unchanged.
Step 10: Repeat Steps 3–9 until the user selects Exit.
Step 11: Stop.
