Step 1: Start the program.
Step 2: Read the number of campus buildings and their names.
Step 3: Initialize an adjacency list to represent the campus graph.
Step 4: Read the number of pathways and the indices of the two buildings connected by each pathway.
Step 5: Add each pathway to the adjacency list in both directions.
Step 6: Read the starting building index.
Step 7: Display the initial campus graph.
Step 8: Perform BFS from the starting building and display the traversal order and number of reachable buildings.
Step 9: Perform DFS from the starting building and display the traversal order and number of reachable buildings.
Step 10: Display all buildings unreachable from the starting building and identify isolated buildings.
Step 11: Ask the user whether a new building should be added.
Step 12: If yes, read the building name and add the new building to the graph. Otherwise, continue.
Step 13: Ask the user whether a new pathway should be added.
Step 14: If yes, read the two building indices, validate them, and add the pathway. Otherwise, continue.
Step 15: Display the updated campus graph.
Step 16: Perform BFS and DFS again from the same starting building.
Step 17: Compare the traversal results and the number of reachable buildings before and after the update.
Step 18: Display whether campus connectivity has improved.
Step 19: Display the updated list of unreachable and isolated buildings.
Step 20: Read the source and destination building indices to check path availability.
Step 21: Use BFS to determine whether a path exists between the two buildings.
Step 22: Display an appropriate message: “Path exists,” “No path exists,” or “Invalid building index.”
Step 23: Stop the program.
