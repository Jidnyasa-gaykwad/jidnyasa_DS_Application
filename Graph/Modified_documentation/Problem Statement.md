Develop a C++ program to represent campus buildings as vertices and pathways as edges in a graph. Apply Breadth-First Search (BFS) and Depth-First Search (DFS) from a user-selected starting building to analyze campus connectivity.

Modify the program to allow users to add new buildings (vertices) and pathways (edges) dynamically and display the updated graph. Compare the BFS and DFS traversal orders and the number of reachable buildings before and after the graph update. The program should also handle disconnected buildings and unavailable paths by displaying appropriate messages and identifying isolated buildings.

This modification demonstrates the practical application of graph traversal algorithms, dynamic graph updates, and connectivity analysis in campus network management.
